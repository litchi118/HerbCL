# HerbCL

Official repository for the paper **"HerbCL: Task-isolated Continual Learning for Cross-Device Chinese Herbal Microscopic Image Recognition."**


## Dataset

The cross-device Chinese herbal microscopic image benchmark developed in this study is publicly available via Baidu Netdisk.

- **Download link:** [Chinese Herbal Microscopic Image Dataset](https://pan.baidu.com/s/1uBxRFrJ6-UmLK35Xd7BFYg)
- **Access code:** `axbr`
  

## Status

🚧 **This repository is under construction.**

**The benchmark dataset and source code will be released here upon acceptance of the paper.** Please check back later, or ⭐ star / watch this repository to be notified when the release is available.

## What will be released

- **Benchmark dataset**: 5,384 microscopic images of 12 herbal materials from the clinical formula Baizi Yangxin Wan, collected under two imaging domains, with predefined incremental task splits.
- **Source code**: training and evaluation code for HerbCL.
- **Reproduction scripts**: configuration files and instructions to reproduce the main results.
